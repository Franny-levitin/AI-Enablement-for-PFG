# PRD

The intent of the website is to design the next iteration of the AI Enablement Hub on SharePoint to enhance learning, adoption, and knowledge sharing needed to support the AI Front Door.

## Design handoff

This is a design handoff made up of three parts:

1. **Wireframe** — `index-wireframe.html` and the pages in `pages/` (`learn.html`, `ai-tools.html`, `use-cases.html`). These show the actual page layouts.
2. **Sitemap** — `sitemap.html`, which outlines the structure and relationships between the pages.
3. **Shared components** — `ds-components.html`, which documents reusable layout patterns (e.g. the Topics section options) for reference so patterns can be repeated consistently across pages.
